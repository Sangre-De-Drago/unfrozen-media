# unfrozen-media

Rendered reels and covers for Unfrozen Music (@unfrozen.music), served by GitHub Pages so Instagram, Facebook and YouTube can fetch them for publishing.

- `drafts/<brief_id>/<variant>.mp4` and `.jpg` - variants produced from a brief in the desk.
- `test/` - a 5-second check clip used to confirm the platforms accept files from this host.

Published at https://sangre-de-drago.github.io/unfrozen-media/
